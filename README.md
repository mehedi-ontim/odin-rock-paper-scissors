# Rock Paper Scissors

A console-based Rock Paper Scissors game created as part of
The Odin Project Foundations course.

## How to Play

1. Open `index.html` in a web browser.
2. Open the browser developer console.
3. Enter rock, paper, or scissors when prompted.
4. Play five rounds against the computer.
5. View the final result in the console.

## Built With

- HTML
- JavaScript
