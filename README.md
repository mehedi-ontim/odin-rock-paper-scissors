
# Rock Paper Scissors

An interactive Rock Paper Scissors game built as part of
The Odin Project Foundations course.

## How to Play

1. Open `index.html` in your browser.
2. Click Rock, Paper, or Scissors.
3. The computer randomly selects its move.
4. View the round result and running score.
5. The first player to reach 5 points wins.
6. Refresh the page to start a new game.

Tied rounds do not award points to either player.

## Features

- Interactive buttons for player choices
- Random computer selections
- Round-by-round results
- Live scoreboard
- Automatic winner announcement
- Disabled buttons when the game ends

## Built With

- HTML
- JavaScript
- DOM manipulation
- Event listeners
